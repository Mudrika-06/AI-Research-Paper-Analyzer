# ResearchLens AI

AI-Powered Research Paper & PDF Analyzer

## Overview

ResearchLens AI is a Python-based NLP application
that analyzes academic research papers and PDF documents.

It uses traditional Natural Language Processing,
machine learning and information retrieval techniques.

## Features

- PDF text extraction
- Text preprocessing
- TextRank summarization
- TF-IDF keyword extraction
- Extractive question answering
- Automatic quiz generation
- Study notes generation
- Research paper comparison
- Word and text exports

## Technology Stack

- Python
- Streamlit
- NLTK
- Scikit-learn
- PyMuPDF
- Sumy
- Pandas

## Installation

pip install -r requirements.txt

## Run Application

streamlit run app.py

## API Requirements

No external AI API key is required.
